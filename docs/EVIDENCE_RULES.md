# EVIDENCE_RULES

## 证据等级

- `A1`：公司官方披露 + 可验证产品/收入/量产/订单
- `A2`：公司官方披露 + 业务存在但规模不清
- `B`：研报/公开资料支持，缺官方细项
- `C`：观察池证据，不可单独驱动结论
- `D`：反证或剔除证据

## 证据类型

- `company_filing`
- `investor_relation`
- `research_report`
- `market_data`
- `financial_metric`
- `policy_event`
- `global_anchor`
- `manual_note`
- `counter_evidence`
